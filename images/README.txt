Put your image files in this folder using these exact names
(or rename them and update the "src=" in index.html to match):

logo.png       -> your full logo image (the one with </> and IKD
                  together) shown top-left in the header/footer
profile.jpg    -> your photo for the Home section (optional).
                  profile.png also works if that's the format
                  you have — just use one or the other.
project1.jpg   -> screenshot for Project 1
project2.jpg   -> screenshot for Project 2
project3.jpg   -> screenshot for Project 3
project4.jpg   -> screenshot for Project 4
project5.jpg   -> screenshot for Project 5

.jpg, .png, or .webp all work fine — just keep the file
extension matching what's written in index.html, or change
index.html's src="images/xxx.jpg" to your file's actual name.

Recommended sizes:
- logo.png: roughly 160x40 px (or similar wide/short ratio),
  transparent background works best
- project screenshots: roughly 1200 x 800 px (3:2)
